# Carbnb Full-Stack Prototype

This project now includes:
- a PHP backend with MySQL database access
- API endpoints for bookings and payments
- a mobile-friendly frontend shell
- a responsive renter payment experience

## Run locally

1. Start Apache/MySQL with XAMPP
2. Open the project folder in your browser via XAMPP htdocs
3. Visit:
   - http://localhost/Capstone4/Carbnb4/home.php
   - http://localhost/Capstone4/Carbnb4/mobile/index.html

## API endpoints

- /api/health.php
- /api/bookings.php
- /api/payments.php
